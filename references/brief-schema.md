# 底稿输出模板

quick 模式默认使用这个模板。它比完整底稿短，但必须保留判断链。

## 默认模板

```markdown
【分析底稿】

# <议题>

## 一句话判断
<一句有信息增量的判断，不要写“这是复杂因素共同作用”。>

## 这件事先分三层看
- 数据层：<真的变了吗？没有可靠数据就说不确定。>
- 传播层：<谁在放大它？它为什么容易被反复说？>
- 体感层：<一个具体人会在什么时刻感到这件事？>

## 真正起作用的条件
1. <条件一：抽象判断 + 具体画面>（把握度）
2. <条件二：抽象判断 + 具体画面>（把握度）
3. <条件三：抽象判断 + 具体画面>（把握度）

## 心理上是怎么转起来的
<客观处境 → 主观评估 → 情绪 → 行动倾向 → 后果 → 二次评估。重点写主观评估。>

## 可能我们想错了
<直觉解释是什么；它漏掉了什么；另一个解释会给出什么相反预测。>

## 说到底
<一句话收束。不是总结，是能继续成文的核心洞察。>

---

### 成文素材
- 可以写成开头的瞬间：
- 核心句候选：
- 一个人物速写：
- 可以直接用的类比：

### 还可以往哪聊
1. ……
2. ……
```

## 写法要求

1. 不用“维度 / 透镜 / 机制 / 范式”这些内部词。
2. 不用“人们 / 年轻人 / 当代人”空泛集合名词；尽量换成具体人。
3. 每个抽象判断后面给一个画面。
4. quick 模式只标关键判断的把握度，不把整篇写成审稿表。
5. 底稿不是摘要。它要让用户看见判断是怎么来的。

## 深度模板

用户要求完整底稿时，改用 `references/handoff.md` 里的完整规范。
