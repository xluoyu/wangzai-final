# 产出规范：底稿怎么写，成文怎么来

本文件是「分析 → 输出」的唯一规范，**按阶段分两半**：

- **上半（一~三节）底稿写作** —— **默认交付物**，怎么写得能读、能讨论。**阶段二、三（出底稿、迭代底稿）只读这半。**
- **下半（四~九节）成文交接** —— 底稿怎么变成第二份交付物（口播文案或文章稿）。**阶段四（用户发指令后）才读这半。**

> 口播成文的风格细则（八段结构、钩子写法、敏感词表、转译表、三重复检、引用核查规程）在 `styles/wangzai.md`；微信公众号文章的适配规则在 `styles/wangzai-article.md` 和 `platforms/wechat-official.md`，**本文件不重复**。
> 去 AI 味（AI 指纹、词汇/句式/结构黑名单）在 `de-ai.md`，**它管两份产物，两个阶段各过一遍**。
> 三者冲突时，**一切以旺仔为准**——它是最终形态的规格。
> 下文中涉及八段口播结构、口播行长、最后两行固定尾音等规则，只有在成品形态为口播稿时适用；微信公众号文章以文章形态、公众号平台和 `styles/wangzai-article.md` 的规则为准。

## 一、底稿五条硬规则

### 1. 术语要"翻译"，不是"使用"
**错**：「上行社会比较导致相对剥夺感上升，进而引发持续的自我评价焦虑。」
**对**：「以前你跟同班同学比，现在你跟全网最会展示的那批人比。你涨薪一千，同事涨薪五百，你还是难受——因为参照对象换了。」

规则：**先说人话，术语最多跟在括号里当注脚。** 一句话删掉术语就不成立，说明你没懂。

### 2. 抽象必须配具体画面
每提出一个抽象概念，立刻跟一个可感的场景。检验方法：**这个场景能不能被画出来？**

- 「参照系上移」→「凌晨一点，你刷到大学同学在新加坡的落地窗前喝咖啡」
- 「承诺恐惧」→「他不是不想结，是不敢签一份没有退出条款的合同」
- 「情绪劳动」→「被客户骂完，转头对下一位顾客笑着说'您好'」

### 3. 用具体的人，不用集合名词
**禁用**：「人们」「年轻人」「当代人」「大众」「现代人」——这些词一说出口，文章就死了。
**改用**：「一个二十八岁、在二线城市做运营的女孩」「一个在互联网公司做后端的程序员」「你隔壁工位的同事」。

规则：**给人物一个身份、一个处境、一个具体时刻。** 不需要真实，需要典型且可感。

### 4. 数字要变成体感
**错**：「初婚年龄推迟了 3.2 年。」
**对**：「以前二十六岁还没着落家里就急了，现在三十二岁还在挑，没人觉得奇怪。」

规则：数字要么换算成日常体感，要么干脆不写。**一个读者能想象的生活状态，胜过一万个精确数字。**

### 5. 可以像文章一样呼吸
段落长短交错；允许短句独立成段，用来砸重点；允许有观点句、有语气、有停顿。

## 二、底稿禁用词

**通用禁用词（AI 高频词、学术措辞、填充短语）全部在 `de-ai.md` 二、三节，不在这里重复。**
本节只列**底稿特有**的三类——内部分析时难免出现，写进给用户的文字里就露馅：

| 禁用 | 替代 |
|---|---|
| 机制 / 维度 / 透镜 / 范式 / 认知框架 | （行文中根本不出现，只在内部分析时用） |
| 个体 / 主体 / 客体 | 人 / 他 |
| 这一现象 / 该群体 / 此机制 | 这件事 / 他们 / 这个东西 |

**「透镜」「维度」「机制」这三个词是内部工具词，不允许出现在给用户的文字里。**

## 三、底稿开篇的四种写法（**仅底稿，成文不适用**）

> ⚠️ 这四种只出现在底稿里，不是成文的开篇规则。
> 成文必须用**现象钩子**（见 `styles/wangzai.md` 写作铁律），且**特别禁止下面的第 3 种**——
> "你有没有过这种时候"式的自言自语铺垫是口播内容的划走点，在成文里属于违规开场。

好的开篇不是"随着社会的发展"，是一个能让人停下来的具体瞬间。

1. **一个人的具体时刻**
   > 周六下午三点，她把相亲对象的微信删了。对方没做错什么，条件也合适。她只是想到接下来几十年都要这样过，忽然喘不上气。

2. **一个反常识的判断**
   > 结婚的人变少，可能不是因为大家不想结了，而是因为大家把结婚看得太重了。

3. **一个所有人都经历过的微小瞬间**
   > 你有没有过这种时候：一天什么都没干，但累得不想说话。

4. **一个具体的问题，直接问读者**
   > 你上一次毫无目的地坐在一个地方，是什么时候？

## 四、两阶段交付

**默认只交【分析底稿】。**【口播文案】或【文章稿】是**按用户指令产出**的第二份，不是每轮都给。

```
默认（阶段二、三）：
【分析底稿】← 完整拆解，带把握度，可讨论、可反驳

收到「输出终稿」指令后（阶段四）：
定稿版底稿 → 🔒 用户确认 → 【口播文案 / 文章稿】← 一份完整、可直接使用的成品
```

**底稿的地位没有降低**——它是用户判断结论可不可信的依据、是后续修改的入口，更是成文的**唯一依据**。
**只给成文、不给底稿，等于把推导过程藏起来；底稿没定稿就成文，等于把用户的修改意见丢掉。**

**底稿的三条硬要求：**

1. **完整** —— Step 0–6 逐项落地，不许用"综上""总的来说"概括掉
2. **带把握度** —— 每条判断后面括号轻标 🟢🟡🔴，不做成表格
3. **附画面素材** —— 末尾给"可写成开头的瞬间 / 可用的类比 / 人物速写"，这是成文的原料库

### 成文的前置动作：先出「定稿版底稿」

**用户发出「输出口播稿」或「输出文章稿」指令后，第一步不是写稿，是合并。**

多轮迭代里，用户推翻过的结论散落在各轮对话中。直接把"最后几轮的意见"当成定稿，会出现**最难查的一类错误：稿子和用户签字确认过的底稿不一致**。

**合并清单（逐条核对，别凭印象）：**

| 核对项 | 问什么 |
|---|---|
| 保留了什么 | 哪几条判断被用户明确认可了？ |
| 推翻了什么 | 哪几条被否掉或改过口径？**改后的版本在哪一轮？** |
| 核心句定了吗 | 最终那句 `A ≠ B` 是哪个？中间换过几次？ |
| 引用定了吗 | 最后选了哪条？有没有被降级成不署名？ |
| 意义层进不进成文 | 底稿里那部分是留在底稿，还是要转译进成文？ |
| 画面素材换了吗 | 四项素材（尤其"能接住固定尾音的瞬间"）以哪一版为准？ |

**合并后重新完整贴出一份底稿，标注「定稿版」，等用户确认。确认后才动笔。**
用户若说"还有一处要改"，就改完再重出定稿版——**不在未确认的底稿上写稿**。

**把握度 🟢🟡🔴 只出现在底稿。** 成文里不许出现——它与旺仔禁用清单里的"研究表明/数据显示"属于同一类破功写法。转化方式：

| 底稿把握度 | 成文里的措辞 |
|---|---|
| 🟢 实证扎实 | 直接下判断：「就是」「已经成为」 |
| 🟡 理论支持 | 「大概」「很可能是」 |
| 🔴 推测/诠释 | 「也许」「说不准」「可以这样理解」——**不用"我猜/我有一种猜测"**，改成无主语说法 |

## 五、分析产物 → 八段结构（映射表）

**成文一律走八段**，13 步细粒度骨架只作参考、不作成文。

（各段的具体要求见 `styles/wangzai.md`「输出规范」第一节，本表只解决"这一步的料从哪来"。）

| 段 | 由本技能的哪一步供料 |
|---|---|
| 1 **钩子** | 事实切片的**体感层**（日常可观察行为） |
| 2 **场景共鸣** | 体感层 + 多维拆解里的可观察项 |
| 3 **情绪痛点** | 情绪链路的"主观评估"那一环 + 自曝规则（第七节） |
| 4 **核心区分** | **反常识检验 + 一句话洞察**——核心句的主产区 |
| 5 **哲学轻引用** | 外部背书（**0–1 处**）。**来源是「已核实引用库 + 候选记录」，不是从 28 个透镜里挑**——透镜是分析框架，其「原理」一行不可直接拿去署名（见第八节）；不需要外部背书时，本段并入第 4/6 段，**不补空话**） |
| 6 **时代场景** | 八维条件扫描（尤其参照系、制度安排） |
| 7 **情绪高潮** | 反常识检验 + 多维拆解的对立项 |
| 8 **认同收尾** | 一句话洞察（改写为认同式，不是判决） |
| **尾音**（不算段） | **固定，不需供料**——但底稿的画面素材要给一个"能接住它的瞬间"（见附录） |

**关键一：核心区分句从哪来。**
本技能的「一句话洞察」通常是判断句（"这不是意愿消失，是标准升高后的推迟"）——**不能直接用**。要把它压成一个 `A ≠ B` 的短句，短到能用嘴说出来：

> 判断句：这不是不想结，是不敢签一份没有退出条款的合同。
> 核心句：`想要的不是婚姻，是一段不会亏的关系`（**≤15 字，能用嘴说**）

**关键二：结尾不是判决。**
本技能的价值判断（铁律 2、3）落到成文里时，**批判对象必须是结构、规则、算法、评价体系——不能是观众**。第 8 段要给的是认同：

> 判决式（违规）：说到底，还是你自己没想清楚。
> 认同式（合格）：这不是玩不起 / 这是你不想只被想要 / 你想被真正认识。

**关键三：认同之后，还有固定尾音。**
第 8 段回收完核心句，**最后两行固定是** `活着其实很好` / `再吃一颗苹果吧`（一字不改、必须有承接，规则见 `styles/wangzai.md`「固定尾音」）。

**底稿要做的事只有一件**：在画面素材里给一个**能接住它的瞬间**——一个此刻能感知的小东西。底稿不用写这两行，但要让成文有地方落。

## 六、德波顿《身份的焦虑》五起因 = 现成骨架

已核实可署名（阿兰·德波顿《身份的焦虑》第一部分）。**五个起因与常见议题方向几乎一一对应**，做身份/焦虑类议题时直接拿来当骨架：

> ⚠️ **口播化提醒（重要）**：这五条算**同一来源的一处引用**，成文里可以一次性带过——"有本书里列过五个原因 / 渴求身份、势利倾向、过度期望、精英崇拜、制约因素"。**但不要再叠加第二位哲学家**：全篇引用额度只有 1 处。
> **额度是 0–1 处**——即"这五条可以整体不引"。先问：这段判断不加德波顿，是不是就变成旺仔的个人意见了？不是的话，0 处更好。
> 另外，**五条不要各自展开成段**（那是论文结构，观众会在第三条划走）。选其中 1-2 条，落到具体场景里讲透，其余作为背景一句带过。

| 德波顿五起因 | 对应本技能 | 可写的内容 |
|---|---|---|
| **渴求身份** | A 族 · 归属与承认（A1 归属需要 / A2 社会计量器） | 人需要被看见，而现代社会的"被看见"信号都是可量化、无上限的 |
| **势利倾向** | B 族 · B2 相对剥夺 / B4 权威迁移 | 势利的本质是只按某一个维度给人排序 |
| **过度期望** | C 族 · C1 可能的自我 / C2 自我决定论 | 期待从父母转向算法推荐的同侪极值 |
| **精英崇拜** | B3 系统正当化 / D4 补偿性控制 | 崇拜的不是人，是确定性 |
| **制约因素** | 八维条件（物质基底、不可逆性） | 不可控的外部条件，是把前四条压实的重量 |

## 七、自曝规则（诚实边界，必须遵守）

旺仔要求前 1/3 有**带真实数字的自曝**，且**用「旺仔」自称**——**全篇不用"我"**（规则见 `styles/wangzai.md` 写作铁律 3、4）。但我们是 AI，**不能虚构经历与数字**——一次编造就毁掉全部可信度，这跟"引用造假是唯一致命伤"是同一条原则。

**按优先级处理**：

1. **用户提供了真实素材** → 直接用，这是最好的
2. **用户没提供** → 用"承认自己也在同一结构里"的写法，不编数字：
   > 旺仔也在被同一套东西推着走。写完这段话的下一秒，旺仔就会去看有多少人读了它。
3. **提示用户补一条** → 在成文末尾加一行：
   > （建议补一条你自己的真实小事替换第 X 段，用「旺仔」自称，带具体数字效果最好）

**禁止**：编造"旺仔有个朋友""上个月旺仔有三天凌晨四点睡的""25年只发了三条"这类具体经历。

> **这条对两份产物都生效**：底稿里若以作者身份说话，同样用「旺仔」，不用"我"。

## 八、引用与冲突裁决

**署名引用一律走 `styles/wangzai.md` 的「引用核查规程」**（归属 → 出处 → 表述三步；核实不了按"换理论 → 去署名 → 整段删除"降级）。本技能引的理论更多，额外强调六点：

- **核实优先于记忆**：出现"我记得有个理论说过…"的念头 → **先搜**。搜不到就不引，**不许拿记忆当出处**。
- **全篇最多留 1 处，可以为 0 处**——判断自己站得住就不引。要引就选那个能用一句人话说清的。⚠️ 韩炳哲论点好但**学术腔最重**，必须整句改写成大白话，或降级为不署名。
- **定引用前先查 `references/content-ledger.md` 记录**：项飙、韩炳哲都已在冷却。冷却不是禁用，是**要写明"为什么这次非他不可"**。
- **合适的都在冷却、或库里没有对口的 → 去 候选记录挑，或按 `rigor.md` 第九节③检索新候选。** 新候选**必须先核实**（归属/出处/表述）才能署名；没核完的写回 4.1。
- **优先使用已核实引用库**（在 `styles/wangzai.md` 中）——它是**"内容账本"（哪些引用已核查过），不是"每期从里面挑一个"的菜单**。**内容存那里，配给（用过几次 / 冷却）存 `content-ledger.md` 记录。**
- **严禁跨书缝合**：《他者的消失》与《妥协社会》不能并成一句"韩炳哲提出"。**这是已发生过一次的真实错误。**
- ⛔ **精神动力学层禁止检索补充**（见 `psychoanalysis.md` 开头的硬禁）。

**心理学实证理论也要能说出来源**：说不出具体研究的，按同一降级顺序处理。

> ⚠️ **别把"引用"和"数据"混成一件事**（两者规则不同）：
> - **署名引用**（谁说过什么）→ 走 `styles/wangzai.md`「引用核查规程」，**可以进成文**（最多 1 处）
> - **数据事实**（是多少）→ 走 `rigor.md` 第九节**三级来源闸门 + 数字三件套**，**只进底稿，不进成文**（成文要把数字转成场景）
>
> 一句话：**引用是"谁说过"，数据是"是多少"。** 前者服务可信度，后者服务判断。

| 冲突点 | 本技能原本的规定 | **最终以谁为准** |
|---|---|---|
| 行长 | 底稿：长短句交错，无硬约束 | **口播文案**：目标 15 字内，≤20 为基线，**硬上限 25 字**；**文章稿**：按自然阅读分句，不套口播行长 |
| **开场** | 可用场景开头，无硬性格式 | **旺仔**：**必须是现象钩子**，禁止"今天要讲的是/我们来聊聊/你有没有想过" |
| 标题/小标题/加粗/emoji/表格 | 允许小标题，表格可选 | **口播文案**：无标题、无小标题、无加粗、无 emoji、无表格；**文章稿**：允许标题与小标题，不用表格和 emoji |
| 把握度标注 | 必须标 🟢🟡🔴 | **加权**：只出现在底稿，成文里转为语气 |
| "研究表明/数据显示" | 未禁止 | **旺仔**：禁用，举证靠思想资源与场景 |
| **结尾** | 一句话洞察 | **旺仔**：不总结；回收核心句 + **给认同，不骂观众不说教** |
| **批判的刀口** | 批判结构，同时保留个体能动性 | **旺仔更严**：刀口只能对着结构/规则/现象，**不能对着观众** |
| **理论引用数量** | 可引多位理论 | **旺仔**：**全篇最多 1 处，可以为 0 处**，且必须口语化 |
| 解法 | 无 | **旺仔**：不给行动清单，只摊开代价 |
| 集合名词"人们/年轻人" | 已禁用 | 一致，**旺仔更严**：用"你" |
| **敏感词** | 无规定 | **旺仔**：对照规避表替换；**禁止拼音缩写/谐音规避** |
| **AI 指纹**（拔高式排比、破折号、填充词） | 无规定 | **`de-ai.md`**：底稿和成文都要过 |
| **作者自称** | 用"我" | **旺仔体**：一律用「旺仔」，全篇不用"我"（例外：引用他人原话） |
| **结尾最后两行** | 一句话洞察收尾 | **旺仔体更严**：认同收尾 → **固定尾音** `活着其实很好` / `再吃一颗苹果吧`，每篇必出、一字不改 |

## 九、分阶段联合自检

> ⚠️ **两个阶段各跑各的，不要每轮全跑。** 底稿阶段跑成文复检是纯粹的浪费——行长、场景密度、段落节奏、可念性这些只有成文才存在。口播和文章分别读取各自的形态、平台与风格规则。

### 【底稿阶段】（阶段二出底稿、阶段三每轮迭代后跑）

0. **底稿完整交付了吗？** 有没有为了省事写成一段摘要、或者干脆省掉？→ 重出，Step 0–6 逐项落地
1. 有没有「人们」「年轻人」这类集合名词？→ 换成具体的人
2. 有没有术语没有翻译成人话？→ 改
3. 每个抽象概念后面，有没有一个能画出来的画面？→ 没有就补
4. 有没有「值得注意的是」「这一现象反映了」？→ 删
5. 删掉所有表格和加粗后，这段文字还读得下去吗？→ 读不下去就是表格腔

**另外两项底稿阶段必须完成**（容易被漏到成文才做，那时就晚了）：

6. **证据分级与 WEIRD 折扣标了吗？检索到的数字过了三级闸门（一手/二手/不可用）与三件套（出处/年份/口径）吗？**（见 `rigor.md` 三、五、九）
7. **引用走完三步核查了吗？**（归属 → 出处 → 表述，见 `styles/wangzai.md`「引用核查规程」）——**底稿里就已经有引用了，此时不核，成文时才发现错了，要连写好的底稿一起重写。**

**最后一道**：底稿过一遍 `de-ai.md`。

### 【成文阶段】（阶段四，收到指令且定稿版底稿已确认后跑）

**先确认前置条件**：① 用户发出了「输出口播稿」或「输出文章稿」一类指令；② 定稿版底稿已获确认。**缺任一条，退回，不写稿。**

**再看成文层。** 行长、场景密度、抽象转译、核心句、敏感词、可念性这些**由旺仔「三重复检」查**，不在这里重复。本节只补它查不到的**四项**：

8. **有没有把结构问题个体化？** 出现"你还不够努力"式归因 → 重写（违反铁律 2）
9. **有没有留下人的能动性？** 通篇都是"结构害的"也不行（违反铁律 3）
10. **把握度 🔴 的内容有没有被写成确定语气？** 有 → 退回底稿核对
11. **自曝给足了吗？** 判据是"**前 1/3 至少一处不虚构的自曝，全篇「旺仔」出现 2-4 次**"。**不用"我"**（引用他人原话除外），所以旧口径"你/我 1.5-2 倍"已彻底作废。
12. **固定尾音是否按成品形态处理？** 口播稿最后两行必须是 `活着其实很好` / `再吃一颗苹果吧`，一字未改；微信公众号文章则在最后一段自然承接这两句，顺序不变，不让尾音空降。

**最后一道**：成文再过一遍 `de-ai.md`（**此时才管行长与可念性**）。

优先级仍然是：**事实正确（引用）> 思想正确（立场）> 文风与口播适配（行长/场景/转译）**。

## 附：画面素材格式（在底稿末尾附上）

```
### 可以被写成开头的瞬间
- （一个具体的时间、地点、动作）

### 可以直接用的类比
- （一个日常物件或场景，能把抽象概念一次讲清）

### 一个人物速写
- （身份 + 处境 + 一个具体矛盾，三句话）

### 能接住固定尾音的瞬间
- （一个此刻能感知的小东西：手边一杯还温着的水、窗外一点声音、果盘里的一个苹果。
  这是给结尾 `活着其实很好 / 再吃一颗苹果吧` 那两行的落点）
```

**这里只是原料区，不是成文**：本环节回答"能给什么素材"，怎么写成稿是 Step 7 旺仔体的事。
**不写标题党、不写分镜脚本**——那些属于拍摄执行层。
