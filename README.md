# Wangzai Final

根据确认后的底稿、账号风格、成品形态和平台规则生成终稿的 skill。

它只负责写成品，不负责从零分析议题。

## 典型输入

```text
根据这份底稿，输出一版旺仔体抖音口播稿。
```

```text
把刚才确认的底稿写成 450-600 字口播稿。
```

## 当前内置能力

- 旺仔体
- 口播稿形态
- 抖音平台
- 底稿到八段口播映射
- 默认 450-600 字口播控制
- 去 AI 味检查
- 平台口播基础规则

## 支持规划

形态规划：

- 口播稿：当前已支持
- 文章稿：未来支持

平台规划：

- 抖音：当前已支持
- 公众号：未来支持
- 知乎：未来支持

当前唯一开放组合是：**抖音 + 口播稿**。

如果请求公众号、知乎或文章稿，本 skill 会先说明该组合尚未开放，不会强行套用抖音口播规则。

## 推荐配合

先使用 `wangzai-brief` 生成并确认底稿，再使用本 skill 生成终稿。
