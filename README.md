# Wangzai Final

根据确认后的底稿、账号风格、成品形态和平台规则生成终稿的 skill。

它只负责写成品，不负责从零分析议题。

## 典型输入

```text
根据这份底稿，输出一版旺仔体抖音口播稿。
```

```text
把刚才确认的底稿写成 450-600 字口播稿。
```

```text
根据确认的底稿，写一篇 1500-2200 字的微信公众号文章。
```

## 当前内置能力

- 旺仔体
- 口播稿形态
- 文章稿形态
- 抖音平台
- 微信公众号平台
- 底稿到八段口播映射
- 默认 450-600 字口播控制
- 默认 1500-2200 字公众号文章控制
- 文章标题、小标题和自然段适配
- 去 AI 味检查
- 平台口播基础规则

## 支持规划

形态规划：

- 口播稿：当前已支持
- 文章稿：当前已支持（仅微信公众号）

平台规划：

- 抖音：当前已支持
- 公众号：当前已支持（仅文章稿）
- 知乎：未来支持

当前开放组合是：**抖音 + 口播稿**、**微信公众号 + 文章稿**。

如果请求知乎、公众号口播或抖音文章，本 skill 会先说明该组合尚未开放，不会强行套用其他组合规则。

## 推荐配合

先使用 `wangzai-brief` 生成并确认底稿，再使用本 skill 生成终稿。
